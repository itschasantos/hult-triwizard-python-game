# TriWizard Python Adventure

Individual Python text adventure by Charlynne Santos. Uses functions, branching, loops, and user input. Inspired by the Harry Potter fictional setting; attribution is retained in the notebook.

## Run locally

Use Python 3 in a virtual environment, install the packages in `requirements.txt`, and open `analysis.ipynb` in JupyterLab. Run cells in order.

## Data

No external dataset is required. Run the notebook interactively; it asks for player input.
